# CGo OpenMap · 青岛

青岛城市数据包，基于 CGo OpenMap 多城市架构制作与维护。

- 城市 ID：`qingdao`
- 城市名称：青岛
- 维护者：YoTra青通
- 主页：https://github.com/YoTraYoungTraffic
- 当前车站对象：**262 个**

本城市包在沿用 CGo OpenMap 通用交互和信息展示方式的基础上，补充青岛轨道交通线网、运营及建设相关数据，并实现青岛城市侧的特色信息展示。

## 功能

### 基础共性功能

- **矢量线路图显示**：线路、站点、换乘站及线路徽标沿用项目原有 SVG 渲染体系。
- **地图交互**：支持拖动、缩放、线路选择、线路显隐等基础操作。
- **明暗主题适配**：线路、文字、面板和图标随项目全局主题切换。
- **站点搜索**：支持中文站名以及 `staname.csv` 中维护的历史名称等搜索索引。
- **车站信息卡**：显示车站类型、运营单位、经停线路、相邻站等信息。
- **线路信息查看**：可在车站信息卡中查看不同线路方向及相邻车站。
- **官网查询**：运营车站保留青岛地铁官网查询入口。
- **PWA 离线支持**：青岛城市数据及运行所需静态资源纳入 Service Worker 预缓存。

### 青岛特色功能

#### 运营与在建线路一体化

- 同一套线网中同时维护既有运营线路和已纳入项目的在建线路、未开通区段。
- 未开通区段沿用项目原有覆盖显示机制，在保留线路识别关系的同时区分运营状态。
- 对共线、分岔以及运营段与建设段衔接位置进行单独处理。

#### 首末车时刻

- 为当前运营线路维护逐站首末班车数据。
- 车站信息卡可按线路和方向显示首车、末车信息。
- 对机场直达列车等特殊运营信息采用单独展示方式。

#### 建设施工进度

- 为在建线路提供车站及相邻区间施工状态。
- 信息卡按“上一区间 / 本站 / 下一区间”的关系组织建设进度。
- 区间可分别显示左线、右线施工节点和日期。
- 分段施工区间可分别显示各施工段及其左右线状态。
- 既有运营车站本身不增加车站施工状态，但与在建段连接的边界区间仍在相邻在建车站中显示。
- 未知日期统一显示为 `—`。

#### 站名沿革

- 对有相关资料的车站显示站名沿革。
- 可记录拟定名称、征集名称、正式名称及后续更名等阶段。
- 展示字号与车站信息卡常规信息行保持一致。

#### 换乘站运营中心覆盖

- 普通车站继续继承所在线路的默认运营中心。
- 对实际管理归属明确的换乘站，使用站级数据覆盖线路默认值。
- 当前仅显示“运营一中心 / 运营二中心 / 运营三中心”，不细分所属站区。

#### 快线线路徽标

- 蓝谷快线、西海岸快线使用专用线路徽标。
- 徽标统一使用项目公共 `assets/svg/` 资源体系。

## 数据文件

### `data_stations.js`

车站基础数据，包括站点 ID、中英文站名、线网图坐标、站名位置与偏移等。

### `data_lines.js`

线路基础数据，包括线路名称、颜色、站序、站间距离、线路徽标及默认运营单位。

### `data_legend.js`

线路图例配置。

### `data_timetable.js`

运营线路逐站首末班车及时刻信息。

### `data_notopen.js`

未开通线路及未开通区段覆盖数据。

### `data_construction.js`

在建线路车站、区间及左右线施工进度数据。

### `data_station_names.js`

车站历史名称及站名沿革相关数据。

### `data_virtual_transfers.js`

虚拟换乘配置。

### `data_scattered.js`

线网图中的城市侧散点元素配置。

### `amap_data.json`

车站地理坐标数据。当前 **262 个项目车站均已建立坐标记录**。

### `staname.csv`

站名搜索索引，沿用原项目兼容的年份列格式。

## 城市模块

`modules/` 用于存放青岛城市侧的车站信息扩展，当前主要包括：

- 首末车时刻；
- 建设施工进度；
- 站名沿革；
- 换乘站运营中心覆盖。

城市侧扩展通过 CGo OpenMap 的城市配置与模块机制实现，尽量保持公共核心逻辑不变。

## 数据约定

- 换乘站按一个独立车站对象统计，不因经过多条线路重复计数。
- 未开通线路仍保留完整线路关系，并通过未开通覆盖层区分运营状态。
- 与既有线路衔接的在建区间，仍属于建设进度的一部分，应显示在相邻在建车站的信息中。
- 施工进度中的未知日期统一使用 `—`。
- 部分换乘站使用站级运营中心覆盖，其余车站继续继承线路默认运营单位。
- 英文多词站名的词间空格使用不换行空格，以保持线路图排版稳定。
