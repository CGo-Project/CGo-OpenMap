# 苏州轨道交通（city/suzhou）

CGo OpenMap 的苏州线网，覆盖 1~8 号线与 11 号线，共 235 座车站（其中 40 座换乘站）。

## 数据来源

- **坐标与走向**：苏州地铁官网「运行线路图」（<https://www.sz-mtr.com/service/guide/map/index_zh.html>）内嵌
  矢量图的官方线网底图。该图本身即正交示意线网，本站直接取其站心坐标与走向折点
  （含站间拐点），按 **K = 0.40** 等比换算到本项目画布坐标系后平移，得到与本图一致的拓扑与比例；
- **站序**：由官方底图的逐段线路图元（`line<站码>to<站码>`）还原，与官方图完全同序；
- **站名**：中文取官方图 `name` 属性（官方用 `/` 表示站名换行，此处合并为完整站名，
  如「苏州园区/火车站」→「苏州园区火车站」），英文取官网英文版线路图（`index_en.html`）同名条目，
  并对 `Lumu/Guxiang`、`Humble Admin-/istrator's Garden` 等机翻断词做了人工校正；
- **线路标志色**：直接取官方图中各线的描边色（1 号线 `#78be20` … 11 号线 `#f1c6a7`）。

## 坐标网格

全部站心与走向折点已统一对齐 **6px 网格**（`x`、`y` 均为 6 的倍数；2026-10-31 全图按 ×1.2
等比缩放后，原 5px 栅格精确映射为 6px，坐标全部保持整数），
人工增删站、挪折点时请继续保持 6 的倍数。注意 `offset`（站名文本微调）不在此列，仍可逐像素调整。
`tools/suzhou_check.js` 会校验网格、站心是否落在本线走向上（作折点或落在折线连线上）、
站序是否沿走向单调前进，以及站名框是否重叠。普通站要求站心精确落在走向上（容差 0.75px）；
换乘站（`tsf` 图元为 17.5px 的圆）允许半个图元（8.75px）——苏州把并行线路从图元两侧引入
（唐庄、西津桥、金尚路、桑田岛），站心落在两线之间是刻意排版，不是线路断开。

## 站间距

官方线路图与官网未公开逐区间里程，为避免「按示意图坐标反算」产生失真里程，
`data_lines.js` 的 `distances` 一律以 `"??"` 占位（项目内合规的待补状态）。
后续拿到官方里程或 OSM 轨道几何后，逐项替换即可，长度须与站序保持 `n-1`。

## 未绘制内容（有意留空）

- **在建延伸段**：6 号线东延（桑田岛—华云）、7 号线北延（莫阳—常楼段）在官方图上仍为灰色在建线，
  本站只画运营段，待开通后再补；
- **有轨电车与智轨**：高新区有轨电车 1/2 号线、吴江捷运 T1 示范线属另一套运营主体，
  官方图以浅绿细线区别绘制，本站暂不纳入；
- **上海地铁 11 号线**：花桥站与上海 11 号线换乘，本站只画到花桥，对端线网不属于本城；
- **4 号线支线（红庄—木里）**：该段现由 7 号线贯通运营（官方图亦只画 7 号线），故 4 号线只保留
  龙道浜—同里主线，红庄—木里区段随 7 号线绘制。

## 邻城衔接（上海）

花桥站（M1127）与上海地铁 11 号线跨省换乘。图上以 `SH11`（`foreign: "shanghai"`，官方色 `#871c2b`）
自花桥引出一段换乘色线至画布右缘，与上海线路图影子相接；上海图侧对称地以 `SZ11`
（`foreign: "suzhou"`，`#f1c6a7`）自花桥引至画布左缘。车站信息板提供「在上海线路图中查看花桥」。
`city/data.js` 中苏州与上海互设 `neighbors`（右 / 左，线宽比 5.4 / 7，花桥对准花桥）。
⚠️ 任一城市再次等比缩放后，必须同步重算两侧 `scale` / `offset` 与花桥色线端点。

## 站名排版

`align` / `offset` 由官方图站名标注的方位反推 8 方向，再用「站点图元 / 线路描边 / 相邻站名」三重避让
求解（站名到图元间距 3~30px 自适应）。改完数据请跑一遍自检：

```bash
node city/suzhou/tools/suzhou_check.js
```

要求 **0 错误 0 告警**（含站名框重叠对数为 0），且 `node editor/tests/selfcheck.js` 全通过。

## 版本

改动 `city/suzhou/` 下任何文件后，须同步递增 `sw.js` 的 `CACHE_NAME` 与全站 `?v=` 版本串。
