# 苏州轨道交通（city/suzhou）

CGo OpenMap 的苏州线网：1~8 号线与 11 号线共 **9 条运营线路、246 座车站**（含 41 座换乘站），
另有 4 号线北延、7 号线北延共 10 座在建车站与 8 段在建虚线。

## 数据来源与来历

- **2026-11 全网重画**：由城市主理人使用 OpenMap Editor 整体重绘（`openmap_project.json` 为编辑器工程文件），
  坐标、走向、站序均以重画结果为准；车站 ID 为编辑器生成的 `node_*` / `station_*`。
- **站序**：按实际运营顺序排列——运营段沿走向从起点到终点；在建延伸段排在该线站序的起点端
  （4 号线：观塘路 → 漕湖大道 → 莫阳 → 太阳路 → 龙道浜 → … → 同里；
  7 号线：春秋路 → … → 雪南 → 常楼 → … → 木里）。莫阳同时属于两条在建延伸段。
- **中英文站名**：中文沿用主理人录入名（含「倪浜·阳澄数谷」「江星桥南站」等新版站名），
  英文取官方英文线路图（`index_en.html`）同名车站；2026-11 起 4/7 号线在建段新增车站用拼音
  （如 `Taiyang Lu`、`Caohu Dadao`）。**246 座车站均已填写 `en`**。

## 坐标网格

站心与走向折点一律落在 **5 的倍数**上（重画时按 25/50px 主干排布），其中 129 座站心、170 个折点
正好在 10px 栅格上。人工增删站、挪折点时请继续保持 5 的倍数；`offset`（站名文本微调）不受此限。

画布 `mapSize` 为 **2000×2100**，内容外接盒 x 14.7..1939.4、y 113.9..2011.1（含站名框）。

## 站间距

官方未公开逐区间里程，`data_lines.js` 的 `distances` 一律以 `"??"` 占位（项目内合规的待补状态），
长度与站序保持 `n-1`（含在建站）。

## 在建与未绘制内容

- **在建延伸段**：4 号线北延（龙道浜—观塘路，含太阳路/莫阳/漕湖大道）、7 号线北延（常楼—春秋路，
  含雪南/朱泾/莫阳/石港路/永昌路/春光路）以 `data_notopen.js` 的灰色虚线绘制，站点为 `type: "no"`；
  它们列在所属线路站序的端部，但几何上画在虚线层而非运营段实线走向上——自检脚本因此对 `type: "no"`
  跳过「站心落在走向上」与「站序单调」两条校验。
- **有轨电车与智轨**：高新区有轨电车 1/2 号线、吴江捷运 T1 属另一运营主体，暂不纳入。
- **上海地铁 11 号线**：花桥与上海 11 号线同站换乘，本城只画到花桥，对端线网不属于本城。

## 邻城衔接（上海）

花桥（`node_556`，坐标 `(1825,2000)`）与上海 11 号线花桥（`(85,693)`）同站换乘。图上以
`SH11`（`foreign: "shanghai"`，官方色 `#871C2B`）自花桥引出一段换乘色线至画布右缘，与上海线网影子相接；
车站信息板提供「在上海线路图中查看花桥」（跳到上海并选中花桥、居中到其坐标）。

**接缝做法**：`SH11` 的折点不是随手画的 45° 斜线，而是把上海 11 号线的 `pathPoints-main`
按 `5.4 / 7` 映射到本城坐标后**截到画布右缘 x = 2000**（`(1825,2000) → (1863.1,1990.8) →
(1912.6,1942.5) → (1995.4,1860) → (2000,1856.8)`）。这样本城的红色接驳线与影子里那条淡色上海 11 号线
在位置、切线、线宽上都连续，边缘不会出现断头或错台。该线是本城唯一的 `foreign` 线，
自检时豁免「折点落 5px 网格」这一条（它必须贴着映射点）。

`city/data.js` 中苏州与上海互设 `neighbors`（右 / 左，线宽比 5.4 / 7）：
`苏州 = offset + 0.7714 × 上海` → `(1759.43, 1465.4)`；`上海 = offset + 1.2963 × 苏州` → `(-2280.74, -1899.59)`，
花桥在两图中严格重合（对端上海图侧以 `SZ11` 自其花桥引至左缘）。⚠️ 任一城市再缩放或移动花桥后，
必须同步重算两侧 `scale` / `offset` 与两条示意线的端点，两线端点必须落在各自的画布边缘上。

## 车站资料（高德地图 / 街区示意图 / 结构示意图 / 设施）

### 周边地图卡片（高德瓦片）

车站信息板顶部的「周边地图」微缩视窗（`stacard/script.js` + `amap_data.json`，与福州同一套做法）：
以高德切片为底图，在本站真实经纬度处落针，支持按钮 / 滚轮缩放（12~18 级）。

- 坐标取自**高德地铁图** `https://map.amap.com/service/subway?srhdata=3205_drw_suzhou.json`
  （9 条线路 / 275 条站点记录，GCJ-02，与高德瓦片同坐标系，**不要再做 WGS-84 → GCJ-02 转换**）；
- 站名匹配四级：精确 → 完整归一化键 → 基名键 → 站名+「站」；归一化会去掉 `(地铁站)`、全角括号与末尾「站」，
  并支持 `A·B` 取前段（`倪浜·阳澄数谷` 命中的是高德图上的 `倪浜`）；
- 覆盖 246 座车站中的 **234 座**；4 / 7 号线在建延伸段 11 站高德尚未收录、`倪浜·阳澄数谷` 之外均已命中，
  缺坐标的站**不渲染空卡片**（`hasCard` 直接返回 false）。

### 官网资料栏

车站信息板「车站信息」页签另有一栏官方资料（模块 `modules/suzhou_station_info.js`，order 15）：

| 板块 | 内容 | 数据来源 |
| --- | --- | --- |
| 街区示意图 | 官网《街区示意图》：出入口编号、周边道路与公交站点；附「在高德地图中搜索本站」 | `entranceAndExitImg` |
| 车站结构示意图 | 官网《站层示意图 3D》：站厅层 / 站台层 / 通道 / 出入口的竖向关系 | `stationFloorPlanImg` |
| 车站设施 | 卫生间、无障碍电梯、车内轮椅固定位、其他设备（市民卡充值机等）、周边公交（按出入口分段） | `toilet` / `accessibleElevator` / `wheelchairParking` / `stationAttr1` / `busChange` |
| 周边景点 | 官网文旅名录外链 | `travels` |

- 数据文件 `data_station_info.js`（约 175 KB）由官网接口 `POST /admin/stationInfo/getStationInfoById.do`
  按站抓取后按本城车站 ID 整理，覆盖 **224 座**（11 座在建站官网暂无资料）。
- 官网原图单张 1~7 MB，因此**默认不下载**：点「查看大图」才载入浮层（含加载态、Esc/点遮罩关闭、加载失败提示）。
- 站名与官网写法不一致的三处已做归并：`苏州园区火车站`＝官网`苏州园区/火车站`、`陆慕古巷`＝`陆慕/古巷`、
  `倪浜·阳澄数谷`＝`倪浜`。

## 站名排版

`align` / `offset` 由排版求解器按「站名框互不重叠、不压本线走向」自动选取（8 方向 + 0/4/8/12px 微调）。
改完数据请跑：

```bash
node city/suzhou/tools/suzhou_check.js     # 要求 0 错误 0 告警、站名重叠 0
node editor/tests/selfcheck.js             # 全站回归
node scripts/check-site-version.mjs        # 版本号一致
```

## 版本

改动 `city/suzhou/` 下任何文件后，须同步递增 `sw.js` 的 `CACHE_NAME` 与全站 `?v=` 版本串。
