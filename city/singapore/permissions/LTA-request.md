Subject: Permission enquiry — Singapore rail map geometry and Public Transport Symbol in an open-source interactive map

Dear LTA team,

I am Deming ZHOU (GitHub: https://github.com/betaxiaozhou/), contributing a Singapore rail map to CGo OpenMap (https://github.com/NokiaimuL/CGo-OpenMap). This is an independent community project and is not endorsed by LTA.

I would like to clarify permission for:

1. Extracting and adapting the rail-line and water/island vector geometry from your Chinese system map `SM_CH_(Ver210726)_CCL6.pdf` into an interactive map with our own open-source fonts and station-code shapes.
2. Using the Sentosa Express pictogram from that map's legend, with the side decorations removed and a reversed colour version for dark mode.
3. Using the Public Transport Symbol shown in the J-Walk Signage Guidelines (PDF page 9), with monochrome green/light-green versions as the Singapore city icon.

The implementation includes coordinate transforms, slightly wider background-colour route casings, interactive selection and dark-mode rendering. It does not redistribute the original PDF or LTA Identity font. Source attribution and a non-endorsement notice would be retained.

The code repository uses AGPLv3 and the contribution guidelines specify ODbL 1.0 / CC BY-SA 4.0 for contributed data. The repository is publicly downloadable and forkable, and those licences allow downstream commercial use. We are therefore asking specifically whether the assets may be hosted, adapted and redistributed in this context, and under what attribution/licensing conditions. We do not assume that a permission for non-commercial display alone would permit open-licence redistribution.

Could you confirm the rights holder(s), the permitted uses and modifications, and whether a separate third-party asset licence or prior review of the final rendering is required? If any of the items cannot be authorised for this context, please let us know so that we can redesign or replace it before requesting upstream inclusion.
