注意（加载方式决定配色是否生效）
CSS 自定义属性只在 SVG 被内联进页面时才跟随主题（本项目线路徽标走 svg-icon-placeholder → fetch + innerHTML，属于内联，可正常生效）。
若改用 <img src> 方式加载（如 SCATTERED_DATA 的装饰物）， SVG 处于独立文档、拿不到页面变量，此时会回落到上方 fallback 的亮色取值。
因此新版写入的是 var(--text-color, #00263b) 这种带回退的形式，两种加载方式都不会崩。
